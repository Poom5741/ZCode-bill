# Purpose Map — ZBILL-M1

## Intended outcome
The ZCode fork (Poom5741/ZCode-bill) builds and launches as a native macOS app showing the 3-panel shell, and a billing skill generates monthly EV-charging reimbursement reports (xlsx+PDF) from local receipt folders

## People affected
Small companies in Thailand with EV-charging allowances (buyers); Poom (maker); future customers' finance staff (users)

## Success signal
pnpm install + build succeed; app launches with file tree / AI / output panels; invoking the billing skill on fixture receipts produces xlsx+PDF visible in the output panel

## Non-goals
Gmail OAuth wizard (M2); re-branding/theming (M3); Windows/Linux packaging (M4); multi-tenant billing

## Human purpose gate
This map is a draft. A human confirms that this is the intended purpose, or corrects it. Technical implementation choices are deliberately outside this gate.
